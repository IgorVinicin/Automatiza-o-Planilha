#Automatização de Cadastro de Itens via Excel

Este projeto é uma ferramenta em Python que automatiza o cadastro de itens em sistemas a partir de uma planilha do Excel. Ele foi desenvolvido para agilizar processos manuais de inserção de dados, reduzindo erros e economizando tempo.

Funcionalidades:

Leitura automática de planilhas Excel (.xlsx ou .xls).

Extração de informações de cada linha/coluna de forma estruturada.

Cadastro automatizado de itens no sistema destino (pode ser adaptado para diferentes plataformas).

Registro de logs para acompanhar o status de cada cadastro.


Tecnologias Utilizadas:

Python

- Openpyxl
- Pyautogui
- Pyperclip
- Tkinter


Como Usar:

Prepare sua planilha Excel com os dados organizados por colunas.

Configure o script para apontar para a planilha correta.

Execute o script e acompanhe o log de cadastros.
